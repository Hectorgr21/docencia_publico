# Nomenclatura de archivos

**Entregables del alumno**
```
<CLAVE>_<matrícula o equipo>_<etapa>_<elemento>_v###.<ext>
AAEV_2023001_B12_solve_v001.blend
```
- Tres dígitos de versión siempre. Sin acentos, espacios ni caracteres especiales.
- Prohibidos: `final`, `definitivo`, `bueno`, `ultimo`. Un archivo terminado no se sobrescribe; se guarda como versión nueva.

**Archivos del paquete docente**
- `P<n>_Manual_del_Estudiante`, `P<n>_Manual_del_Docente`, `P<n>_Diapositivas`
- Banco de ejercicios: `Banco_T<n>_<Tema>_Manual_del_<Estudiante|Docente>.docx`
- Láminas: `Lamina_Vertical_Carta_<Tema>.pdf`
